# Agent instructions

These instructions are for coding agents that work in this repository. For the catalog rules,
setup, and verification, see [CONTRIBUTING.md](CONTRIBUTING.md). For the visual design, see
[DESIGN.md](DESIGN.md).

## Branches

- A merge to `main` deploys to production at `https://internal-agents.com/`. Make changes on a
  branch and merge them through a pull request.
- `claude/plan-017-source-intake-pipeline` is an experimental branch. Keep it: do not delete it
  when you clean up branches. Do not merge it into `main`, and do not open a pull request that
  merges it, without explicit approval from a maintainer.
